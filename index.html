LorePulse Uploader

A personal publishing tool for the LorePulse YouTube channels.

LorePulse makes short daily news recap videos (YouTube Shorts) about finance, entertainment, technology and world news. LorePulse Uploader is a private desktop tool that runs on the creator's own computer and publishes those videos to the four YouTube channels that LorePulse owns.

It uses the YouTube API Services to upload videos, set their thumbnails, and read the channels' own analytics. It is not a public service: there is no sign-up, and nobody other than the channel owner uses it.
