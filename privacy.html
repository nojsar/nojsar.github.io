Privacy Policy

LorePulse Uploader. Effective October 26, 2026.

LorePulse Uploader is a private desktop tool that the LorePulse channel owner runs on their own computer to publish videos to the four YouTube channels they own. It has no other users.

YouTube API Services

This tool uses the YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data it accesses

  • Basic information about the signed-in channels (channel ID and name), to confirm which channel is linked.
  • The channels' own videos: it uploads videos, sets thumbnails, changes privacy status, and lists the channels' uploads.
  • Aggregate analytics for the channels' own videos (for example views and watch time) and comments on those videos, read-only.

It does not access any other YouTube channels or users' data.

How the data is used and stored

The data is used only to publish videos and to compare how the channels' videos perform, so future videos can be improved. It is stored locally on the owner's computer. Sign-in tokens are stored in a private folder on that computer. Comment text is overwritten on each run.

No data is sold, shared with third parties, or shown to anyone else. The tool does not use cookies or collect information about any device other than the owner's computer.

Revoking access

Access can be revoked at any time on the Google security settings page: https://myaccount.google.com/permissions. Locally stored data can be deleted by removing the tool's data folder.
